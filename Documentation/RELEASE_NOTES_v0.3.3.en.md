# Cozy Survivors v0.3.3 — Android Test Release

Release date: September 10, 2026  
Android version code: 6

This test release brings together the recent character, mobile control and save improvements for tester distribution.

## New in v0.3.3

- All test content is unlocked on first launch, including after updating from a version with Unlock all turned OFF.
- After this one-time setup, changes to the Unlock all setting are saved and respected on future launches.
- Updated the Android version to 0.3.3 (version code 6) for tester distribution.

## Included in this build

- Animated capybara and calico cat idle poses in gameplay and character selection.
- Access to all animals, regions, endless modes, decorations and letters with **Test · Unlock all** enabled.
- A saved **Test · Unlock all** toggle in Settings to switch back to normal progression whenever you like.
- Mobile touch instructions, automatic attacks and an on-screen pause button.
- Improved handling of empty run saves and recovery from a valid backup when a save is damaged.

Combat and balance are unchanged from v0.3.2. Unlocking test content does not change earned progress, purchases or stars; rewards earned while playing still count.

Requires Android 8.0 or later on an ARM64 device. This is a development-signed APK for testing.

## Short release notes

All animals, regions, endless modes, decorations and letters are unlocked on first launch, including after updating. You can switch Unlock all off in Settings; your choice is saved for future launches.
