# Cozy Survivors v0.3.4 — Android Test Release

Android version code: 7

- Updated the Android version identifiers for a new test distribution.
- Retained the Unlock all test setting for all animals, regions, endless modes, decorations and letters.
- Preserved saved progress and settings from v0.3.3.

New test profiles start with Unlock all ON. The one-time unlock migration introduced in v0.3.3 still applies when updating from v0.3.2 or earlier. This release does not reset an ON/OFF preference already saved in v0.3.3.

Gameplay and balance are unchanged. This development-signed APK is for direct testing on Android 8.0+ ARM64 devices.

## Short release notes

Updated to version 0.3.4 (build 7) for a new Android test release. Includes the Unlock all test setting and animated capybara and calico cat companions. Saved progress and settings from v0.3.3 are preserved.
