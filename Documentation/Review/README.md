# 개발 빌드 UI 검수

게임의 실제 Canvas를 1280×720 렌더 타깃에 출력한 이미지입니다. 숨김 창에서는 일반 스크린샷 API가 동작하지 않아 같은 UI를 오프스크린 렌더링했습니다.

- 01: 타이틀
- 02: 동물·지역·난도 선택
- 03~05: 동물별 공격, 지역별 장애물과 목표
- 06: 성장 선택
- 07: 보스 진입
- 08: 승리 결과
- 09: 영어 UI와 큰 글씨 설정

검수를 위해 무기 레벨, 적 배치, 목표와 보스 상태를 주입했습니다. 자연 진행 플레이테스트나 상용 아트 완성의 증거로 사용하지 않습니다. 사용자 저장과 별도 프로필을 사용했습니다.
