# Android 테스트 전체 해금 · v0.3.4

개발용 APK와 Unity 에디터에서는 **전체 해금 ON**으로 처음 설정됩니다. v0.3.2 이하에서 업데이트하면 기존에 OFF였던 저장도 최초 한 번 ON으로 전환합니다. 이후 사용자가 선택한 ON/OFF 상태를 저장하며 재실행 시 덮어쓰지 않습니다. v0.3.3에서 v0.3.4로 업데이트할 때는 이미 저장한 설정을 유지합니다.

## 사용

1. 타이틀의 **설정 · 조작**을 엽니다. 플레이 중에는 일시정지 → 설정으로 들어갑니다.
2. 왼쪽 아래 **테스트 · 전체 해금: ON/OFF** 버튼으로 전환합니다.
3. 새 모험의 설명 줄에서 테스트 전체 해금 상태를 확인합니다.

## 적용 범위

- 동물 3종, 지역 3곳, 각 지역의 무한 모드.
- 장식 12종의 미리 배치, 편지 9개의 열람.
- 전투 중 레벨·무기 성장과 난도는 기존 규칙을 사용합니다.

옵션 전환은 실제 클리어·업적·구매 내역·보유 별을 변경하지 않습니다. OFF로 바꾸면 실제 진행에 맞는 콘텐츠만 열립니다. 진행 중인 모험은 계속할 수 있으며, 다음 동물/지역 선택부터 해금 조건이 적용됩니다. 테스트 해금 중 실제로 플레이해서 얻은 보상과 클리어는 정상적으로 기록됩니다.

이 버튼과 해금 우회는 `UNITY_EDITOR || DEVELOPMENT_BUILD`에서만 동작합니다. 일반 Release 빌드는 저장된 테스트 ON 값이 있어도 실제 진행 조건을 사용합니다.
